# PhishAware 0.4.0: Unit 4 initial implementation

The first working prototype. A participant can give consent, take the counterbalanced
pre-assessment, read six lessons, and practise on six scenarios with immediate feedback.

## Highlights

- **M1 Consent & Session**: versioned consent, adult confirmation, a random UUID4 identifier, and withdrawal that deletes every linked record (FR-01, FR-02, FR-10).
- **M2 Assessment Engine**: counterbalanced 12-item pre-assessment with idempotent answers (FR-03).
- **M3 Learning Content**: six one-minute lessons, one per phishing cue (FR-04).
- **M4 Practice & Feedback**: six practice scenarios with immediate, cue-level explanations (FR-05, FR-06).
- **M5 scoring functions**: score, learning gain, cue error rates, SUS score, and counterbalancing.
- **M8 Security**: CSRF tokens, allowlist validation, parameterized SQL, CSP headers, hardened cookies, and logs without IP addresses (NFR-08 to NFR-12).

## Quality

- 39 automated tests (unit, black-box, data-integrity, and security).
- GitHub Actions workflow with flake8, pytest, Bandit, and pip-audit.

## Not yet included

The post-assessment (FR-07), results page (FR-08), and SUS survey (FR-09) are planned for 0.5.0.
