# PhishAware 0.5.1: Unit 5 testing completion

A testing release. No application behaviour changed; the test suite and tooling did.

## What changed

- **Coverage measurement**: statement coverage is now measured with coverage.py (`coverage run -m unittest discover -s tests -t . && coverage report`), and the CI workflow fails below 90%.
- **12 new tests (78 in total)**: six black-box navigation tests walk the dashboard through every step, open the lessons and withdrawal pages, and try out-of-order requests; six more cover an existing database surviving a restart, the `reset-db` command, analytics with too few participants, the report format for edge cases, an unbalanced form, and chart bar widths at their boundaries.

## Result

| | 0.5.0 | 0.5.1 |
|---|---|---|
| Tests | 66 | 78 |
| Statement coverage of `src/` | 94% (40 of 651 statements missed) | 100% (0 of 651 missed) |
| `src/modules/progress.py` | 44% | 100% |

Statement coverage shows which lines ran, not that every behaviour is correct, so the black-box tests continue to check responses and stored records rather than lines.
