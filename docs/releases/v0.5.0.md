# PhishAware 0.5.0: Unit 5 core logic and unit testing

This release completes the learner-facing core. A participant can now go from consent
to the post-assessment, see a personal before-and-after comparison, and rate the system.

## Highlights

- **Post-assessment (FR-07)**: twelve items from the participant's second form. Odd-numbered sessions take Form A first and Form B last; even-numbered sessions take the reverse, so a difference in form difficulty cannot look like learning.
- **Results and analytics (FR-08)**: a personal results page with scores, a per-cue chart, and the cues to practise next; `flask --app src.app analytics` reports the mean gain, its standard deviation, the paired t statistic, Cohen's d_z, error rates by cue, and the mean SUS score without printing any identifier.
- **Usability survey (FR-09)**: the ten-item System Usability Scale with allowlist validation.
- **Core-logic demo**: `python scripts/demo_core_logic.py` runs the algorithms on inputs that can be checked by hand.

## Quality

- 66 automated tests (27 new): white-box tests for the scoring and analytics functions, and black-box tests for the post-assessment, results page, survey, and command-line tools.
- The assessment engine is now phase-generic, so the post-test reuses the tested pre-test path.

## Defects found by tests and fixed

- Command-line tools raised "Working outside of application context" under Flask's test runner. Every command now uses `with_appcontext`.
- `sus_score` accepted `True` as a rating because `bool` is a subclass of `int`. Boolean ratings are now rejected, and the boundary-value test remains as a regression guard.
