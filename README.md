# PhishAware
An interactive web-based application to improve phishing awareness among university students (MSIT 5910 Capstone, University of the People).

## Folders
- `src/` – Flask application (one module per folder under `src/modules/`)
- `data/` – fictional scenario bank only (no personal data)
- `tests/` – unit and acceptance tests
- `design/` – architecture, flow, ER, and branching diagrams
- `docs/` – requirements, reports, meeting notes

## Branches
- `main` – stable, submitted versions (tagged per unit)
- `develop` – integration branch
- `feature/*`, `docs/*` – short-lived task branches merged via pull request

## Commit convention
Conventional Commits + requirement ID, e.g. `feat(M1): add consent page [FR-01]`
